What is CI/CD?

CI (Continuous Integration) means every change you push is automatically checked, for example by running tests, so mistakes are caught early.

CD (Continuous Deployment) means every change that passes those checks is automatically released to the live website, with no manual upload.

How this page gets here

  1. You edit this page on your computer and run git push.
  2. GitHub Actions starts automatically and runs the tests.
  3. If the tests pass, GitHub Actions tells Render to deploy the new code.
  4. Render builds and starts the new version of the site.
  5. GitHub Actions checks that the live site is running the new code.
  6. If any step fails, GitHub emails you and the old version stays live.

Try it

Change the green "Version" line above in templates/index.html, push it, and watch the Actions tab on GitHub. A minute or two after it turns green, refresh this page.
